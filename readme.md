# Expense Tracker — UI / UX Design Phase

This repository contains the **UI/UX design implementation** for the Expense Tracker application.

All pages are built using:
- Plain HTML5
- Vanilla CSS
- Mobile-first responsive design
- Placeholder-only data (no logic, no backend)

---

## 📌 Project Status
**Design Phase (UI only)**  
No backend or frontend logic is implemented yet.

---

## 📂 Pages Overview

| File | Description |
|----|-----------|
| index.html | Login / Signup page |
| dashboard.html | Post-login dashboard |
| add-expense.html | Add expense screen |
| transactions.html | Transactions list |
| insights.html | Insights & analytics |
| components.html | Design system (internal use) |

---

## 🚀 How to Run the Project (Local)

### Option 1: VS Code Live Server (Recommended)

1. Open the project folder in VS Code  
2. Install **Live Server** extension  
3. Right-click `index.html` → **Open with Live Server**

You will get a link like:
### http://127.0.0.1:5500/index.html
